# Sieniseikkailu 🍄

A mushroom-picking adventure game developed using **Godot v4.5.1**.

## 📋 Overview

**Sieniseikkailu** is an engaging adventure game created by a group of students at **TurkuAMK** as part of a course assignment for the Spring 2025 semester. The game challenges players to explore natural environments and collect various mushrooms while navigating through an immersive gaming experience.

The project demonstrates practical game development skills using the powerful Godot game engine, featuring custom gameplay mechanics, interactive environments, and engaging mechanics designed to provide a fun and educational gaming experience.

## 🎮 Gameplay

- **Explore** diverse environments in search of mushrooms
- **Collect** different types of mushrooms with unique characteristics
- **Navigate** through adventure scenarios and challenges
- **Experience** an immersive mushroom-picking adventure

## 🛠️ Technology Stack

- **Engine**: Godot v4.5.1
- **Language**: GDScript (100%)
- **Platform**: Cross-platform (Windows, macOS, Linux, Web)

## 📦 Requirements

- **Godot Engine v4.5.1** - [Download here](https://godotengine.org/download/)
- A modern web browser (if running the web version)
- Minimum system requirements:
  - 512 MB RAM
  - OpenGL 2.1+ compatible graphics card

## 🚀 Getting Started

### 1. Installation

**Option A: Using Godot Editor**
1. Install Godot v4.5.1 from [godotengine.org](https://godotengine.org/)
2. Clone this repository:
   ```bash
   git clone https://github.com/ADCREW-LLC/Sieniseikkailu.git
   ```
3. Open Godot and import the project folder

**Option B: Running Pre-built Executables**
- Look for release builds in the [Releases](https://github.com/ADCREW-LLC/Sieniseikkailu/releases) section (if available)

### 2. Running the Game

**In Godot Editor:**
- Press `F5` or click the Play button to start the game
- Use `F6` to run a specific scene

**Standalone Build:**
- Run the executable directly from your system

## 🎮 Controls

- **Movement**: Arrow Keys or WASD
- **Interact**: Space Bar or Left Mouse Button
- **Menu**: ESC (pause/return to menu)
- **Look Around**: Mouse movement (if applicable)

*Refer to in-game help for complete control mapping*
